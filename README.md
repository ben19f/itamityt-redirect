# Itamityt Redirect Service

Переход по `GET /rserv/{link_id}` записывает событие в таблицу `clicks` и
перенаправляет пользователя на URL из `items.description`. Для события
сохраняются идентификатор ссылки, IP-адрес клиента, User-Agent и время.

Число переходов для существующей ссылки можно получить через
`GET /rserv/{link_id}/clicks`; ответ имеет вид:

```json
{"link_id": "abc123", "clicks": 42}
```

Изменения схемы `clicks` вносятся Alembic-миграцией backend-сервиса. Если сервис стоит за reverse proxy,
`request.client.host` может быть адресом самого прокси; для корректного IP
нужно настроить доверенную обработку forwarded-заголовков на уровне инфраструктуры.
